# PostgreSQL database

ฐานข้อมูลขั้นปัจจุบันมี 4 ตารางเท่านั้น

| ตาราง | หน้าที่ |
|---|---|
| `source_files` | ข้อมูลไฟล์ PDF/รูปที่รับเข้ามา เช่น ชื่อไฟล์ ชนิดไฟล์ และจำนวนหน้า |
| `documents` | ข้อมูลส่วนหัว ผู้ออก ลูกค้า และยอดรวมของแต่ละเอกสาร |
| `document_line_items` | รายการสินค้า/บริการ แยกเจ้าของด้วย `document_id` |
| `billing_note_entries` | รายการ invoice ที่อยู่ในใบวางบิล |

## ความสัมพันธ์

```text
source_files
    |
    +-- documents
            |
            +-- document_line_items
            |
            +-- billing_note_entries
```

ข้อมูลจากใบเสนอราคา ใบแจ้งหนี้ ใบเสร็จ และใบวางบิลไม่ใช้ row ร่วมกัน
ทุกไฟล์สร้าง `source_files` และ `documents` ใหม่ เพื่อให้เปรียบเทียบข้อมูลข้ามเอกสารได้ภายหลัง

## รูปแบบ ID

| ข้อมูล | ตัวอย่าง ID |
|---|---|
| ไฟล์ต้นฉบับ | `FILE-000001` |
| ใบเสนอราคา | `QUO-000001` |
| ใบแจ้งหนี้ | `INV-000002` |
| ใบวางบิล | `BIL-000003` |
| ใบเสร็จรับเงิน | `REC-000004` |

รายการย่อยไม่สร้าง ID สุ่มอีก แต่ใช้ `document_id` คู่กับ `line_number`
เช่น `QUO-000001` แถวที่ `1` คือรายการแรกของใบเสนอราคาใบนั้น

Schema จะถูกสร้างอัตโนมัติเมื่อ PostgreSQL container เริ่มครั้งแรกจาก
`database/schema.sql`

`source_files` ไม่เก็บ `ocr_engine` เพราะระบบหลักใช้ Typhoon OCR เพียงตัวเดียว
และไม่เก็บ `byte_size` เพราะขั้นตอนปัจจุบันยังไม่ได้ใช้ขนาดไฟล์ในการตรวจสอบ
หรือรายงานผล
